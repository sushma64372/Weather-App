# 🌤️ Weather App Using Python

## 📌 Project Description
A Python-based Weather Application that fetches real-time weather information for Indian cities using the Open-Meteo API.

Users can enter a city name and get current weather details.

## 🚀 Features
- Search weather by Indian city name.
- Display current temperature.
- Show feels-like temperature.
- Display humidity percentage.
- Show wind speed.
- Display weather conditions.
- Check weather for multiple cities.
- Handle invalid city names and connection errors.

## 🛠️ Technologies Used
- Python
- Requests Library
- Open-Meteo API

## ⚙️ Installation & Execution

1. Clone the repository.
2. Install the required library:

```bash
pip install requests
```

3. Run the application:

```bash
py weather_app.py
```

4. Enter an Indian city name to get its current weather.
